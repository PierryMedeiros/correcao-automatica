# Repo de exemplo do job fake

Fixture sintética da F2: faz o papel do repositório de um aluno para o runner ter o que clonar,
sem depender dos golden repos (§17.2, pendência humana que destrava a F3 e a F7).

Não é entrega de aluno de verdade e não deve virar uma: o que ele exercita é o caminho
`clone → checkout no SHA pinado → carga`, não a qualidade de uma correção.
